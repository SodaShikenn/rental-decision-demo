# Rental Helper

**候補を比べて、自分に大切な条件を見つける。**

賃貸物件の画像や掲載リンクから、候補の違いと根拠を整理し、対話を通じて希望を具体化するツールです。最初に「暮らしの希望」を作文する必要はありません。候補を見ながら条件を確認し、内見や不動産会社への相談に使えるメモを作ります。

## 採用担当者の方へ

このプロジェクトでは、物件情報の抽出だけでなく、「候補はあるが、何を優先するか決められない」という入居者の課題を扱っています。出典付きの比較から質問を作り、利用者が確認した希望だけを判断材料にします。不足情報や別の部屋の価格を、確定した情報として扱いません。

## 3つの操作で体験する

比較ワークスペースでは「費用・広さ・駅と買い物・設備と契約・一覧」を切り替え、候補を見ながら横のパネルで希望を整理できます。スマートフォンでは2件を選んで比較し、下のボタンから質問を開きます。画像を押すと拡大できます。現在の版を操作するには[ローカル起動](docs/DEVELOPMENT.md#run-locally)を使います。

<details>
<summary><strong>01：候補の違いと、情報の根拠を見る</strong></summary>

月額や初期費用を押すと、内訳と出典を確認できます。画像・リンクから追加でき、不明な項目を残したまま比較を始められます。OCRの詳細は必要なときに開きます。

GRAN PASEO明大前Ⅳは賃料・部屋番号のない建物図面です。同じ建物の102号室の掲載を根拠に「参考 12.3万円/月」を表示しますが、候補の部屋と一致していないため予算判定には使いません。API設定時は不足する月額情報を自動調査し、同じ建物・住所・部屋の現在の募集条件が確認できた場合だけ補完します。

</details>

<details>
<summary><strong>02：具体的な違いから、希望を一つずつ確認する</strong></summary>

AI相談は候補を分析してから質問し、回答をもとに希望を提案します。利用者が承認するまで条件に反映しません。迷った場合は保留でき、後から考え直せます。

「AIと深める」から相談できます。APIなしで試す場合は「費用 → ひとつずつ確認」で、月額の上限と重要度を選びます。確認した条件に対して、候補ごとの適合・違い・不明点が表示されます。スクリーンショットは実際の数値質問の操作であり、架空のAI会話ではありません。

</details>

<details>
<summary><strong>03：内見・相談に使えるメモを持ち出す</strong></summary>

「条件メモ」には確認した希望、選んだ設備、契約前に聞きたいことがまとまり、編集・コピーできます。候補・画像・回答・メモはIndexedDBでこのブラウザに保存します。

地図の観測結果と、それを含む会話は一時的です。承認済みの希望は残ります。クラウド共有は今後の開発項目です。

</details>

## このプロジェクトで示す取り組み

- **課題設定：** OCR検査中心の画面を、候補比較と希望の発見を中心とする体験に変更。
- **フルスタック開発：** JavaScript ES Modules、FastAPI、構造化スキーマ、外部API、IndexedDBを接続。
- **AIの扱い：** 根拠ID・物件照合・明示的な承認・古い応答の無効化・障害時の代替操作。
- **UI/UX：** 比較と質問を同時に表示、確認した希望の表示、モバイルの2件比較、キーボード操作、必要に応じて開く詳細。
- **検証と運用：** ロジック/APIテスト、プロバイダのスタブ、ブラウザ確認、Docker、GitHub Actions。
