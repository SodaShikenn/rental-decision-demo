EXPLAINABLE RENTAL SEARCH

条件検索の先へ。
暮らし方から、住まいを選ぶ。

家賃や駅徒歩だけでなく、通勤、夜の買い物、帰宅時間、静けさを一緒に比較。 候補ごとの利点と妥協点を、対話で言語化するデモです。

物件・賃料履歴・レビューはデモデータ Google Maps API は任意接続
