# Rental Helper — walkthrough transcript

Simulated demo. Recorded listing data and scripted AI responses; real application interactions.

## 00:00:00 — Compare the homes you are already considering.

Recorded listing images become a side-by-side view. No requirements essay to get started.

検討中の候補から比較を始めます。画像と記録済みの掲載情報を使い、最初に希望を書く必要はありません。

## 00:00:05 — A reference price is not a confirmed rent.

Inspect the source and room identity. Another unit's offer stays outside the budget calculation.

別室の参考価格は、候補の確定賃料にしません。根拠と部屋の一致を確認します。

## 00:00:15 — Let the candidates start the conversation.

This AI exchange is scripted for the demo. The interface, evidence controls and actions are real.

候補の違いから質問します。この動画のAI応答は録画専用の固定データです。画面と操作は実際のアプリです。

## 00:00:26 — Choose a direction. Confirm the interpretation.

A tentative answer is not a saved requirement. Only your confirmation changes the comparison.

回答だけでは希望を保存しません。提案された解釈を本人が確認してから比較に反映します。

## 00:00:39 — Check the commute without retyping every address.

Tokyo hub menu + outbound/return Maps links. Set the 08:00 / 18:00 schedule inside Google Maps.

通勤先を選ぶと各候補の行き・帰りリンクを用意します。朝8時到着・夕18時出発はGoogle Maps側で設定します。

## 00:00:52 — Leave with a brief you can explain.

Confirmed priorities and unanswered questions are assembled automatically. No manual diary.

確認した希望と次の質問をメモに自動でまとめます。手入力の内見日記ではありません。

## 00:01:02 — Preview what leaves your browser.

Review the content, then save an HTML brief. Hosted share links need a connected backend.

共有する内容を確認してHTML保存。期限付きリンクにはバックエンドが必要です。

## 00:01:14 — Explore the product. Then inspect the engineering.

Try the public demo, follow the code tour, or run the project locally. Links are in the README.

公開デモを試し、コードツアーで設計を確認できます。READMEから各ページへ進めます。
